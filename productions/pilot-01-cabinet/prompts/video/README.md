# 《打不开的柜门》视频生成包 v1

## 使用顺序

1. 每次只生成一个镜头，不把六个镜头一次性交给模型。
2. 同时上传该镜头的首帧和尾帧；若平台只支持一张参考图，优先使用首帧，并把尾帧作为第二轮校正参考。
3. 复制对应镜头文件中的“实际提交提示词”，保持目标时长、固定机位和负面约束不变。
4. 先生成无声版本；通过画面验收后再剪辑、配音效和配乐。
5. 镜头1与镜头6必须逐帧检查包脚丝袜；镜头4与镜头5必须始终保持女主脚部在画外。

## 镜头文件

- `shot-01-motion-v1.md`：收纳、离场、猫拉门失败；3.5秒。
- `shot-02-motion-v1.md`：PCB进入外壳、遥控器完成；3.5秒。
- `shot-03-motion-v1.md`：按键、执行器解锁、柜门开启；3.0秒。
- `shot-04-motion-v1.md`：猫爪伸向零食、女主返回拿手机、对视；3.0秒。
- `shot-05-motion-v1.md`：关门、推开遥控器、坐正装无事；3.0秒。
- `shot-06-motion-v1.md`：摸猫、手动开柜、喂食、进食；4.5秒。
- `qa-checklist.md`：视频抽帧验收清单。

## 平台参数建议

- 画幅：9:16。
- 帧率：24 fps。
- 镜头运动：全部固定机位；关闭自动运镜、自动变焦与镜头重构。
- 动作强度：低到中；角色身份稳定优先于动作幅度。
- 风格：写实电影感，只有动作节奏略带动画化可读性。
- 若平台只支持5秒：按5秒生成，剪辑时等速或局部变速到目标时长，不删除关键因果动作。

## 首个测试

先运行镜头1。只有镜头1通过身份、离场方式、手机位置、猫科动作和丝袜逐帧验收后，再批量生成镜头2–6。
