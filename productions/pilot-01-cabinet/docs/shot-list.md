# 分镜清单 v2

## 全片服装连续性

女主统一为浅粉偏象牙色短款睡裙、肉色微透肉哑光天鹅绒包脚连裤袜、浅粉色薄底零跟露趾拖鞋。半蹲、站立与蹲下镜头均不得换成外出服、高跟鞋或裸腿。只要脚趾入镜，必须看见连续袜头张力线和覆盖趾缝的袜面，红色甲油只能隔着袜面朦胧透出；脚部细节不可小到无法验收。

## 镜头1｜0.0–3.5秒｜固定中广景

- 画面：暖色现代居家厨房/餐边区域。女主半蹲，把透明无字鱼肉零食袋放入低柜，扣上防宠物锁；手机留在柜旁台面。猫咪在一旁观察。
- 关键动作：女主离开后，猫咪只尝试拉一次柜门；柜门晃动但未打开。
- 叙事功能：同时建立鱼肉、锁、手机与猫咪的动机。

## 镜头2｜3.5–7.0秒｜低机位近景＋微距插镜

- 画面：柜旁灰色电子工作垫，猫咪坐在后方。前景是小型电路板、深灰色单键遥控器外壳和微型执行器。
- 关键动作：猫爪将电路板推入外壳，状态灯亮起；不表现复杂的人类手指式操作。
- 叙事功能：说明遥控器是为解决锁扣障碍而制作。

## 镜头3｜7.0–10.0秒｜柜门侧面低机位

- 画面：执行器已固定在锁扣附近，猫咪与柜门同框。
- 关键动作：猫爪按下遥控器；锁扣释放，柜门向外缓慢开启。
- 叙事功能：兑现前一镜建立的方案。

## 镜头4｜10.0–13.0秒｜柜内反打

- 画面：从柜内鱼肉零食旁向外看。猫爪伸入；背景中女主回来拿手机并停住。
- 关键动作：猫爪与女主同时静止，双方对视半拍。
- 叙事功能：制造被撞见的转折。

## 镜头5｜13.0–16.0秒｜双角色中景

- 画面：猫咪坐在柜门前，女主站在后方。
- 关键动作：猫咪收爪、按键关门、把遥控器推开、坐正并移开视线；动作连续但不慌乱。
- 叙事功能：完成“假装只是在测试”的无声表演。

## 镜头6｜16.0–20.5秒｜低位温暖近景

- 画面：女主蹲在猫咪身旁，与低柜构成三角关系。
- 关键动作：摸猫一次；手动开柜；拿出一份零食放下；猫咪低头快速进食；女主看着它微笑。
- 叙事功能：以宠溺关系和自然情绪释放收尾。
