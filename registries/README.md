# Registries

`assets.yaml` is the index of stable IDs and current approved versions. Add new characters, props, materials, outfits, and environments here without changing the generic directory model. Character IDs follow `CHR_<TYPE>_<NNN>_<ALIAS>`; environment IDs follow `ENV_<TYPE>_<NNN>_<ALIAS>`. `current_canon_version` stays `null` until an approved version is locked; consumers must never assume the newest folder is active.
