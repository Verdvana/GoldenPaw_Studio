# Tech Cat L0 Reference Guide

`L0_CAT_001` (`1.jpg`) is currently the only identity source. Use it whenever a Gate-2 cat face or front-view candidate needs L0 identity, but never pretend it defines unseen angles.

## It may define

- frontal face shape and muzzle impression;
- eye color/shape, nose, ear placement;
- visible golden-shaded front coat and tipping impression;
- seated front-body proportions.

## It may not define

- exact profiles, back/top coat distribution, tail, paw pads, or rear proportions;
- cat-sized Vision Pro or MacBook scale by itself;
- lighting/background as Canon;
- any invented detail created in a previous AI output.

## Before locking cat Canon

Add real photos if available: left/right profile, left/right 3/4, standing side, back/top coat, tail, paws, and neutral daylight coat color. Until then, mark those Canon components `BLOCKED_BY_SOURCE_COVERAGE` rather than propagating generated guesses.
