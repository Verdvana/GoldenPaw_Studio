# 命名规范

## 基础原则

- 目录名和资产文件名使用英文、数字与下划线。
- 文档正文可以使用中文。
- 已经投入生产的 ID 不回收、不改作其他资产。
- 镜头被删除后，其编号也不复用。

## ID 前缀

| 类型 | 前缀 | 示例 |
|---|---|---|
| 角色 | `CHR` | `CHR_CAT_001` |
| 整套造型 | `LOOK` | `LOOK_WOMAN_001` |
| 服装单件 | `GAR` | `GAR_COAT_001` |
| 鞋 | `SHO` | `SHO_LOAFER_001` |
| 袜子 | `SOC` | `SOC_BLACK_001` |
| 配饰 | `ACC` | `ACC_EARRING_001` |
| 设备 | `EQP` | `EQP_APPLEWATCH_001` |
| 道具 | `PRP` | `PRP_MUG_001` |
| 场景 | `LOC` | `LOC_HOME_001` |
| 镜头 | `SH` | `S01E001_SH010` |

## 镜头文件

推荐形式：

```text
S01E001_SH010_TK003_v002.mp4
S01E001_SH010_KEYFRAME_A_v004.png
```

- `SH010`：镜头编号，预留插入新镜头的空间
- `TK003`：第三次生成或拍摄尝试
- `v002`：同一次素材的第二个加工版本
