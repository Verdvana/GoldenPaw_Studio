# 审核清单

状态：初始框架。

## 角色

- 女主是否仍像同一个人
- 身高、头身比、肩胯比例是否一致
- 发型、发长、分缝和发色是否连续
- 猫咪脸型、毛色、眼睛和尾巴是否一致
- 人猫比例是否可信

## 服装与设备

- 鞋类是否仅无鞋、平底鞋或 5cm 高跟鞋；高跟姿态是否误拉长腿
- 袜面是否连续跨越趾间，避免独立趾套／裸趾染色；红甲是否在袜层下隐约透见
- 强弯曲处是否仅有符合参考材质的轻微褶皱；泳衣下袜腰／缝线是否只留下合理表面轮廓而不直接外露

- 女主是否按要求搭配连裤袜；脱鞋或露趾鞋是否仍保持完整包脚袜体
- 脚趾甲是否维持红色设定，其可见度是否服从袜层透度，而非错误裸皮化
- 大面积纯色区是否出现色块、明暗斑驳或跨版本色偏；详见 [质量控制](color_and_fabric_quality.md)

- 服装单件和穿着层级是否正确
- 鞋袜关系是否正确
- 首饰和设备是否位于正确身体侧
- 产品外形、屏幕、接口和佩戴方式是否正确

## 镜头

- 光源方向与天气是否一致
- 空间布局、轴线和视线是否连续
- 动作是否能从上一镜自然进入下一镜
- 是否出现肢体融合、穿模、瞬间变形或背景漂移
