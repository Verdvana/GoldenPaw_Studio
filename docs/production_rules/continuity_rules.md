# 连续性规则

## 女主强制造型连续性

- 鞋类仅无鞋、平底鞋、5cm 高跟鞋；同镜组固定款式和高度，不通过更改腿长表现高跟鞋。
- 包趾织物跨趾间张力、踝前／腿弯轻微褶皱随姿势与材质变化；不得突然变成逐趾贴皮或松垮堆袜。
- 基准层级为袜在泳衣内，袜腰本体不露出，泳衣表面仅允许材质支持的轻微厚度轮廓。

- 日常以裙装为主且必须搭配连裤袜；固定双脚红色脚趾甲油，不推定手指甲也涂红色。
- 默认包脚连趾袜，脱鞋／露趾鞋时袜面仍覆盖足背、脚底和脚趾。红甲可透见程度服从袜子实际透度，不为露出甲油生成裸趾。
- 同场镜头固定袜色、织物、厚度／透度、趾部结构及鞋袜层级；详见 [强制约束](../../library/wardrobe/CHR_WOMAN_001/mandatory_constraints.md)。

状态：初始框架，后续补充。

每个正式镜头至少检查：

- 时间、季节、天气与光线
- 女主脸部、身材比例、发型与表情承接
- 猫咪毛色、体态、四肢与尾巴
- 服装穿脱状态、纽扣、袖口、褶皱和湿润状态
- 鞋袜组合、袜口高度、裤脚或裙摆遮挡关系
- Apple Watch 的手腕、表带、表盘和袖口遮挡
- MacBook Pro、Vision Pro 的型号外观与使用状态
- 道具位置与左右手
- 空间布局、视线、轴线和动作承接

每集可以改变季节和服装，但必须在该集的前期清单中明确声明。
