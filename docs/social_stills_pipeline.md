# 社媒静态内容生产线

## 定位

社媒静态内容（Social Stills）与短视频生产线并列。它直接生产可发布的单张图片或同一主题下的轮播组图；不是视频截图工具，也不以任何先前生成图作为人物、身体、猫、固定道具或材质的生成来源。

每张成图均为 L3 发布级静图。它可以在通过 QA 和明确发布批准后发布，但不会自动提升为 L1 Canon，也不能作为未来生成的身份或固定资产输入。它若被用于同组图的连续性，仅能定义位置、取景方向、临时物品摆放、动作过渡与时间氛围。

## 内容与目录模型

```text
social_posts/
  CONTENT_PILLARS.md
  <SERIES_ID>/
    <POST_ID>/
      POST.md
      TEMPORARY_ASSET_BRIEF.md          # 当帖 L2 临时场景/道具的文字规格
      images/<ASSET_ID>/
        REFERENCE_PLAN.md
        PROMPT_ASSEMBLY.md
        qa/QA.md
        candidates/<CANDIDATE_ID>/     # 仅候选输出与其元数据
        approved/                      # 明确批准后移动候选唯一栅格文件至此
```

建议 ID：`SOC_<SERIES>_<NNN>`，例如 `SOC_HOME_001`。轮播中的每张图片另有稳定 `asset_id`，例如 `SOC_HOME_001_IMG_01`。同一帖子可以包含多张 L3 图，但每张都有独立候选、输出路径、checksum 与 QA 条目。

`candidates/` 的 `inputs/` 如需存在，只存放引用和溯源记录，绝不复制 Canon、L0、材质源图或可复用派生图。获批时移动（不是复制）唯一的候选栅格到 `approved/`；原候选记录保留原路径、原 checksum、现批准路径与批准证据。

## 生产流程与审批门

1. 创建帖子规格：确定主题、栏目、平台、单图或轮播、可见角色、环境、服装和临时陈设。
2. 创建引用计划：从 `registries/reference_sets.yaml` 与最近的 `REFERENCE_GUIDE.md` 选择最小引用集，并为每项声明责任与 `must_not_define`。
3. 生成前完成提示词装配记录：必须区分 `generation_inputs` 与 `qa_comparison_only`。主人露脸时，L0/确定性 L0 派生 Face 方法是唯一脸部生成权威；AI Face/Body Canon 只能列在 QA 对照栏。
4. 生成一个候选并记录设置、输出路径和 checksum。未审核或失败候选不得成为任何后续输入。
5. 逐图 QA：通用 L3 QA 加上平台裁切、轮播连续性与生活真实感检查。
6. 用户明确批准发布后，记录批准决定，并将候选唯一文件移动到批准路径。发布批准不是 Canon 批准。

没有完成第 1–3 步的记录，不得调用任何图像生成工具。用户应当逐帖或逐个明确批准生成门；本流程本身不授权批量生成。

## 栏目边界

| 栏目 | 允许主题 | 真实性重点 | 典型限制 |
|---|---|---|---|
| `HOME_MOMENT` | 晨间、阅读、做咖啡、整理、窗边休息 | 自然光、非中心构图、真实物品层次 | 不改变住宅固定结构或永久装修 |
| `CAT_COMPANION` | 猫陪伴工作、沙发互动、占据设备 | 猫身份、毛色 tipping、比例、固定设备尺度 | 不把其他猫或失败图用作参考 |
| `HOME_ATMOSPHERE` | 雨天窗景、夜间书桌、角落静物 | 自然曝光、可解释的光源、可居住感 | 无人物也不能改写住宅 Canon |
| `OUTFIT_DETAIL` | 日常穿搭、配饰、手部/鞋履细节 | 面料、自然褶皱、真实接触与裁切 | 露出的连裤袜仍须全链路连续 |
| `MICRO_STORY` | 同一天/同一时段的 2–6 张组图 | 光线、服装、道具位置与叙事一致 | 每张独立生成；前图仅连续性参考 |

新增栏目必须先写明其视觉边界与适用 QA，再投入候选生成。

## 平台输出规则

- 每份 `POST.md` 明确主平台、主版式与交付像素；推荐平台版本为 4:5、9:16、1:1，但每个输出是独立构图/独立记录，不能把主图的机械裁切伪装为新 L3 图。
- 原始发布文件和平台版本均遵守“一资产一物理文件”；一个文件有且仅有一个权威资产记录。
- 文案、话题和发布时间属于发布元数据，不具有视觉 Canon 权威。

## 社媒专项 QA

除 `docs/qa/qa_policy.md` 的身份、身体、猫、服装、连裤袜、道具和环境检查外，必须确认：

1. 画面看起来像可信的生活记录，而非模板化棚拍：避免无意义的完全对称、全物品过度整齐、塑料皮肤和不合理的景深。
2. 光源、阴影、反射、景深、曝光和运动模糊互相一致；不以“胶片/颗粒”掩盖生成错误。
3. 主体裁切、文字安全区、画面边缘和平台比例满足指定发布版式；没有水印、伪 UI、乱码或不可解释的品牌标记。
4. 轮播内仅检查声明的时间/物品/服装连续性；任何连续性参考不得覆盖各资产原有责任边界。
5. 若主人露脸，执行脸部污染检查；若连裤袜可见，执行全覆盖链与材质规则检查。

出现身份漂移、脸部污染、猫漂移、连裤袜断裂、固定道具重设计、住宅结构漂移、不可解释文字或不可信物理关系，均为发布阻断项。
