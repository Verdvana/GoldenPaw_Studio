# 图片与视频生成验收规范

## 使用方式

所有新图片、分镜、首尾帧和视频生成任务都必须执行以下流程：

1. 先确认女主是否入镜以及本镜头服装。
2. 若穿连裤丝袜，将丝袜颜色、厚度、光泽和包脚结构写入正向主体描述，不能只放在负面词中。
3. 若露趾鞋或拖鞋使脚趾可见，必须逐字加入 `prompts/_shared/closed-foot-pantyhose-toe-lock.md` 的英文硬锁。
4. 视频提示词还必须声明该结构在每一帧保持稳定，不闪烁、不消失、不变成裸脚。
5. 生成后放大检查脚部；未同时满足下列四项则拒绝该结果并重新生成。

## 露趾鞋袜四项验收

- 脚趾最前方存在一条沿五趾弧线连续、略深、受横向拉力的细窄袜头线。
- 半透明哑光袜面从脚背连续延伸并覆盖所有脚趾，趾缝之间也有完整纱层，不出现裸露缝隙。
- 脚趾轮廓与指甲边缘隔着袜面被压柔、雾化，不能像无遮挡裸脚一样锐利。
- 暗红色甲油只能作为丝袜下方的朦胧酒红色块透出，不能出现清晰甲面边缘或直接高光。

## 材质连续性

- 肉色丝袜不能因为接近肤色而在脚踝或脚趾处视觉消失。
- 从小腿、脚踝、脚背到脚趾应保持同一色调、密度和天鹅绒哑光微织纹。
- 在全身或中远景中，袜头线仍应作为可辨识的细节存在；若画面尺寸不足，应调整机位或构图，而不是省略丝袜证据。

## 视频逐帧规则

- 袜面、袜头线和丝袜下的甲油在脚部可见的所有连续帧中保持同一位置和材质。
- 禁止在运动、蹲下、走动、运动模糊或遮挡恢复后发生裸脚跳变。
- 首帧和尾帧都要单独通过四项验收，视频成片再抽查中间帧。
