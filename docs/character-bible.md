# 赛博金渐层：角色基准 v0.1

## 核心身份

- IP名称：赛博金渐层
- 性别：公
- 年龄：5岁
- 品种：金渐层英国短毛猫
- 核心定位：一只拥有顶尖电子工程能力、梦想吃遍各地鲜鱼与刺身的猫科工程师

## 性格与表演

- 平时面无表情，动作灵活、迅速、精准。
- 内心戏非常丰富，外在保持镇定和专业。
- 面对技术问题立即行动，解决问题时专注高效。
- 提到鱼、刺身和旅行便突然滔滔不绝。
- 被彩色毛球吸引后，会立刻坐正、舔爪，假装自己从未失态。
- 喜剧核心：能力非常强，但猫性永远更强。

## 能力

- 电路设计
- 嵌入式编程
- 芯片设计
- 制作电子小装置

## 愿望与弱点

- 核心愿望：品尝各种刺身和鱼，去不同地方旅行。
- 弱点：彩色、绒毛质感、球形的物体。

## 标志性小动作

- 后脚挠头
- 舔爪子
- 失态后突然坐正
- 心虚时移开视线，但尾巴暴露真实情绪

## 当前科技装备

- Apple Vision Pro
- MacBook Pro

## 与女主角的固定尺寸关系

- 女主角身高：168cm。
- 赛博金渐层为体型偏大的胖成年英短，视觉体重约7–8公斤。
- 四脚站立：背高约30cm，头顶约38cm。
- 自然坐姿：头顶约43cm，明显低于女主膝盖。
- 被女主抱起时，身体宽厚并具有明显分量感，但仍是现实家猫尺寸。
- 坐在约75cm高的书桌上时，头部略高于打开的16英寸MacBook Pro屏幕下沿，低于屏幕顶端。

## 声音建议

现实层只发出猫叫、呼噜和鼻音；内心旁白采用冷静、年轻、略带骄傲的男性声音。

## 视觉不变量

后续所有图像与视频必须优先保持：

1. 胖而灵活的成年公猫体型。
2. 圆脸、饱满腮帮和浓密写实毛发。
3. 暖杏金色、焦糖金色的低对比度渐层毛发；口鼻、下巴、喉部和胸口偏奶油白，避免明显黑色毛尖和深色虎斑感。
4. 大而圆的灰绿至橄榄绿色眼睛，具有自然深色眼线和较大瞳孔。
5. 写实材质结合动画化表情和动作。
6. 首先是一只真实可爱的猫，而不是机械改造猫。
7. 脸型宽而接近正圆，双颊非常饱满；鼻子小而粉，口鼻短而整洁。
