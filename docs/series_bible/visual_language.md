# 视觉语言

## 总体方向

- 真人实拍感，避免明显的 AI 塑料质感。
- 使用电影化构图、光线、景深与镜头运动。
- 摄影设计服务人物情绪和叙事，不以炫技为目的。
- 上海城市环境应具有生活感、空间感和真实天气质感。

## 需要长期控制的内容

- 女主五官、年龄感、身材比例、发型与表演气质
- 猫咪脸型、毛色分区、体态、眼睛、四肢与尾巴特征
- 人猫同框时的尺寸比例
- 高频设备的型号、颜色、佩戴或使用方式
- 经典服装及其鞋袜、配饰和穿着层级
- 场景布局、门窗和家具方位
- 正反打方向、视线、动作承接与光线方向

## 待补充

- 主色调和色彩管理
- 镜头焦段倾向
- 手持、稳定器、轨道与静态镜头的使用边界
- 猫咪主观镜头规则
- 夜景和雨景风格
