# 视频产品工程

`products/` 的每个二级目录代表系列中的一集或一条独立视频工程。工程之间共享固定角色身份与比例资产，但可分别定义服装、场景、剧情和镜头语言。

## 当前工程

- `pilot-01-cabinet/`：试播短片 01《打不开的柜门》。

## 新工程最低结构

```text
products/<视频工程>/
├── README.md
├── brief/
├── storyboards/
├── keyframes/
├── video/
│   └── outputs/
└── qa/
```

工程根 `README.md` 必须让视频生成类 AI 能独立开始工作，至少写明：目标与边界、必读顺序、本地文件清单、引用的全局角色资产、本集造型与场景锚点、逐镜头连续性基准、逐镜头执行方式、输出命名、验收标准、当前状态和下一步。

每集在制作前必须明确：

- 双主角及本集其他固定角色的身份与比例参考。
- 本集服装、配饰、鞋袜关系、发型变化和主要道具。
- 场景平面关系、角色站位、光源方向及跨镜头不变量。
- 对话、反转、反应镜头和喜剧节奏的具体落点。
- 关键帧之间允许变化的动作与必须保持不变的身份、造型、道具和空间状态。

产品目录只保存本片专属内容。可复用角色母版保留在 `assets/`，由工程 README 明确引用，不得复制。
