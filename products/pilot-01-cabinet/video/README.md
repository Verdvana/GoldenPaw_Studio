# 《打不开的柜门》视频生成

执行前先完整读取工程入口：`../README.md`。工程入口定义必读文件、全局角色资产、输出命名和验收流程，本目录说明不能替代它。

## 文件

- `platform-neutral-v2.md`：全片统一视频约束。
- `shot-01-motion-v1.md`：镜头 1，3.5 秒。
- `shot-02-motion-v1.md`：镜头 2，3.5 秒。
- `shot-03-motion-v1.md`：镜头 3，3.0 秒。
- `shot-04-motion-v1.md`：镜头 4，3.0 秒。
- `shot-05-motion-v1.md`：镜头 5，3.0 秒。
- `shot-06-motion-v1.md`：镜头 6，4.5 秒。
- `outputs/`：生成的视频结果；不得覆盖旧版本。

## 固定参数

- 画幅：9:16。
- 帧率：24 fps。
- 镜头：固定机位，关闭自动运镜、自动变焦和镜头重构。
- 动作强度：低到中，身份与物体连续性优先。
- 音频：第一轮无声。

生成后按 `../qa/video-checklist.md` 验收。先测试镜头 1，通过后再依次生成镜头 2–6。
