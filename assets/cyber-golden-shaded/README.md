# 赛博金渐层资产

本目录保存赛博金渐层可跨视频复用的角色资产。

## 权威入口

- 角色设定：`character-bible.md`
- 视觉方向：`visual-direction.md`
- 制作包与资产优先级：`production-pack-v1.md`
- 唯一身份母版：`key-art/cyber-golden-shaded-key-art-reference-v1.png`

## 素材类型

- `key-art/`：身份与关键视觉。
- `turnaround/`：身体结构和多视角。
- `expressions/`：表情与动作锚点。
- `equipment/`：科技装备及交互。
- `motion-tests/`：可复用动作测试、关键帧和视频提示词。
- `references/`：后续确认的补充参考。

每种素材的图片、提示词和类型说明应放在同一三级目录。具体视频的剧情镜头不得放在这里。
