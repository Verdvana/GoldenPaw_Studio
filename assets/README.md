# 角色资产库

`assets/` 只保存可跨视频复用的角色资产。二级目录必须是单个角色或固定角色组合；三级目录按素材类型划分。

## 角色索引

- `cyber-golden-shaded/`：赛博金渐层。
- `female-lead/`：女主角。
- `female-lead-and-cyber-golden-shaded/`：女主角与赛博金渐层的固定双角色关系资产。

女主角与赛博金渐层是系列固定双主角。后续可增加固定角色；新增角色必须建立独立目录、身份母版、身体或体型比例基准及与现有主角的关系资产。

## 目录规则

每个角色目录必须有一个入口 `README.md`，说明身份主基准、素材类型、优先级和使用边界。素材类型目录把以下内容放在一起：

- 正式图片或参考图。
- 与图片对应的生成或编辑提示词。
- 该类型的索引、状态和验收说明。

提示词和角色设定不再集中到独立的根级目录。它们跟随所属角色与素材类型归档，避免图片和说明分离。

## 资产与产品的边界

- 通用角色母版、身份、年龄感、表情、服装、动作、装备、材质和比例属于资产。
- 跨集必须稳定的长相、年龄感和身体比例由角色资产定义；单集服装可以变化，但已确认的复用造型应登记为资产或固定参考集。
- 单条视频的剧本、分镜、关键帧、运动提示词、成片和抽帧记录属于 `products/<视频工程>/`。
- 产品只引用这里的通用资产，不复制母版。
- 新增角色时使用 `assets/<角色短名>/README.md` 作为入口。
