## 角色定位

- 职位：财务主管。
- 核心气质：严谨、可信赖、善于分析，兼具团队管理能力与高层沟通能力。
- 固定配饰：Apple Watch、小耳钉；其余首饰保持简洁。
- 表演原则：情绪克制自然，避免普通文员感、销售式夸张笑容和过度强势表演。
- 鞋履方向：以露脚背的中跟职场鞋为主；当前包含 D’Orsay、后空细带、T 字带和深 V 口后空款，均保持闭趾与完整包脚丝袜连续可见。

## 使用规则

- 日常审核用于锁定她独立处理数据时的专注状态；晨会与指导下属用于团队管理；经营分析与预算汇报用于管理层沟通；月末结账用于表现疲惫到释然的情绪变化。
- 所有裙装均搭配完整包脚连裤袜；丝袜颜色、厚度、透肉度和哑光织物质感以各场景提示词为准，不得变成裸腿、塑料硬壳、乳胶或紧身裤。
- 当前全部使用闭趾鞋。若后续改为露趾鞋并让脚趾入镜，必须完整加入 `assets/female-lead/hosiery/closed-foot-pantyhose-toe-lock.md`。
- 单张参考图可以扩展动作，但必须保持人物、服装、丝袜材质、办公空间和情绪逻辑连续。
- 秋冬图片必须从核心脸部定妆照和身体比例参考全新生成，不得在既有职场成片上二次改衣，以免造成面部涂抹、磨皮和细节退化。
- 秋冬图验收时应保留真实毛孔、自然肤色起伏、清晰眼眉和分离发丝；蜡像皮肤、局部涂抹或美容滤镜效果均判定为不合格。
