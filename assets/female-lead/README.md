# 女主角资产

女主角全局资产以“核心基础资产”和“丝袜专项资产”为主体。经用户明确确认、需要跨多个视频复用的造型可登记为固定参考集；固定参考集只建立索引并引用现有正式原图，不复制图片。

## 路径

- `core/`：唯一的基础资产入口，集中保存核心定妆、脸部与头部身份、身体多视角、表情与动作，共 6 张图片及其对应提示词。
- `hosiery/`：丝袜结构、材质、鞋履适配、生成硬锁与 QA 规范。
- `fixed-reference-sets.md`：用户明确确认的跨项目固定造型与场景参考集；图片仍由其原始专项目录维护。
- `character-bible.md`：女主长期角色设定；不充当图片参考。

## 使用顺序

1. 先读取本文件与 `core/README.md`。
2. 始终以 `core/female-lead-key-art-fresh-v1.png` 作为人物身份最高基准。
3. 根据任务从 `core/` 最多补充一至两张脸部、身体或表情参考，不要默认加载全部 6 张。
4. 服装、场景和镜头连续性由具体 `products/<视频工程>/README.md`、本片文档和本片关键帧决定。
5. 需要复用已确认造型时，读取 `fixed-reference-sets.md`，按参考集职责选择最少图片。
6. 涉及丝袜时，额外从 `hosiery/README.md` 进入并执行其硬锁与验收规则。

## 资产边界

当前不设重复图片目录形式的全局 `outfits/`、`sports/`、`workplace/` 或 `outings/`。只有经过用户明确确认、确实需要跨多个视频复用的图片，才能加入 `fixed-reference-sets.md`；原图保持单一来源，后续替换时同步更新其专项 QA 记录。
