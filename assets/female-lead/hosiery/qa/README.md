# 丝袜资产｜验收与失败案例

本目录保存丝袜资产的专用验收规则、抽帧记录和典型失败案例。失败图片只能用于识别错误，不得作为正向生成参考。

## A. 包脚结构

- 五趾和足底均被同一片袜面完整覆盖。
- 无五指袜式逐趾包裹，无裸露趾缝。
- 袜面在趾间形成连续、柔和、浅凹的张力曲面。
- 袜头前缘无缝合线、加深横线、补强带、滚边或连接边界。

## B. 材质连续性

- 腿部、脚踝、脚背、趾尖和脚底颜色一致。
- 织纹、光泽和透肤度随曲面自然变化，没有在脚趾处消失。
- 材质仍属于织物，不变成裸肤、乳胶、PVC、金属或液体油膜。

## C. 脚趾与甲油

- 脚趾轮廓和甲面边缘隔着袜面被柔化。
- 暗红甲油只以朦胧酒红色块透出。
- 无清晰裸甲边缘、直接镜面高光或皮肤裸露空隙。

## D. 解剖与鞋履

- 左右脚连接身体，脚趾数量和关节正确。
- 无多余脚、空鞋、鞋脚分离或脚穿出鞋底。
- 鞋口和鞋底边缘不冒充袜头连接线。

## E. 姿势与褶皱

- 蹲下时脚踝、脚背、膝前和膝窝的拉伸/压缩方向正确。
- 褶皱强度符合厚度：薄款不出现厚布褶，厚款不保持完全无变化的喷涂表面。
- 花纹和高光随褶皱连续变形，无断裂、漂移或贴图滑动。

## F. 分辨率与可读性

- 正式结构和材质母版长边建议不低于 2048 px。
- 脚部必须清晰对焦并足够大，可以在 100% 放大下检查织纹、袜头前缘和趾间张力曲面。
- 强阴影、过曝、运动模糊或景深虚化不能掩盖关键结构。

## 失败案例分类

- `bare-toes`：脚趾读作裸脚。
- `toe-seam`：出现袜头横线或连接边界。
- `toe-glove`：逐趾紧贴或五指袜结构。
- `material-dropout`：丝袜在脚踝、脚背或脚趾消失。
- `nail-too-sharp`：甲面和高光像裸露指甲。
- `wrinkle-physics`：蹲姿褶皱与厚度或受力不符。
- `anatomy`：脚趾数量、脚型或鞋脚连接错误。

任一 A、B、C 类错误均直接拒绝，不得通过后期说明或文字标签将其登记为合格资产。
