# 丝袜资产｜脚部身份

本目录保存女主脚部身份母版，负责锁定解剖结构，不负责定义具体丝袜材质。

## 待补资产

- 左右脚自然站立的正面与高位三分之四身份图。
- 内侧、外侧和脚底结构图。
- 必要时补充脚踝、小腿下段与脚部的连续比例图。

## 固定内容

- 左右脚尺寸、宽度和脚背高度一致且具有自然细微差异。
- 五趾数量、长度顺序、间距和关节结构稳定，无融合、多趾或缺趾。
- 脚踝、小腿与足部比例忠实于女主身体母版。
- 甲型自然，统一使用暗红色甲油。
- 甲油身份仅作为丝袜下方的颜色来源；正式丝袜参考中不得出现清晰裸露的高光甲面。

## 拍摄标准

- 中性背景、标准白平衡、柔和主光与轻微侧光。
- 脚部完整、无遮挡、无透视夸张，长边建议不低于 2048 px。
- 身份母版可保留不穿鞋的基础解剖参考，但不得被直接当作“穿丝袜合格证明”；实际生成必须同时使用 `construction/` 或 `materials/` 的已验收参考。
