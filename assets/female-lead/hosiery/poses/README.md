# 丝袜资产｜姿势、弯曲与褶皱

本目录保存丝袜在站立、蹲下、屈腿和运动状态中的张力与褶皱参考，重点解决脚踝、脚背、膝前和膝窝在弯曲时的材质连续性。

## 首批待补姿势

| 姿势 | 建议视角 | 检查重点 |
| --- | --- | --- |
| 自然站立 | 正面、侧面 | 基础密度和无褶皱状态 |
| 半蹲 | 侧面、高位三分之四 | 脚踝压缩、脚背拉伸、膝窝轻微堆叠 |
| 深蹲 | 侧面 | 膝前拉伸、膝窝压缩、踝部与小腿过渡 |
| 提踵 | 侧面 | 脚背伸展与前掌受力 |
| 交叠屈腿 | 正面、侧面 | 接触区压缩、花纹和光泽连续性 |
| 蹲起关键帧 | 侧面固定机位 | 视频中褶皱出现、移动和恢复的连续过程 |

## 褶皱物理

- 10D、15D：以细微密度叠加、柔和压缩线和光泽变化为主，不生成厚重布褶。
- 30D、50D：脚踝和膝窝可出现少量细软褶皱；受拉伸一侧更平滑、更透。
- 80D、100D：压缩侧允许更明显但仍柔软的织物褶皱，不能形成硬折纸棱线。
- 羊毛材质：褶皱体积和纤维感可以更明显；不得变成宽松裤袜或与腿部分离的布袋。
- 珠光、缎光和油亮材质：高光随曲率和褶皱连续弯折，不能跨越凹陷保持笔直。

## 姿势不变量

- 无论脚背伸展、脚趾受力还是蹲姿遮挡，丝袜都不能在脚踝以下消失。
- 脚趾仍由连续袜面整体覆盖，不生成五指袜、裸露趾缝或袜头连接线。
- 暗红甲油始终位于袜面下方。
- 屈膝处只改变局部密度、光泽和褶皱，不改变丝袜颜色、材质或厚度身份。
