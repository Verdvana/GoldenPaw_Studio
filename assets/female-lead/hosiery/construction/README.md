## 结构要求

- 只有一层连续袜面，不出现独立袜头、补强袜头或连接线。
- 袜面横向跨越趾间空隙，形成浅而连续的张力曲面。
- 不生成五指袜式逐趾包覆，也不让织物深入趾缝。
- 脚底视角同样必须显示完整袜面，不能因为足底朝向镜头而变成裸脚。
- 暗红甲油隔着袜面呈朦胧酒红色，不显示独立甲面高光。
- 正面与侧面应保留真实足部体积，不能为了展示袜面而把脚趾压成平板。

结构母版是所有厚度、颜色、材质和花纹的共同几何基准。其他目录中的图片不得反向覆盖本目录已经锁定的袜头结构。
