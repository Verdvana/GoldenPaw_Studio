# 丝袜资产｜正式目录索引

本目录用于登记已经通过验收的正式丝袜资产，并生成供人查看的资产总览。当前尚无新资产登记。

## 后续索引字段

每个正式资产至少记录：

- 文件路径和版本。
- 状态：`candidate`、`approved` 或 `deprecated`。
- 厚度、颜色、材质、花纹。
- 视角、姿势、鞋履和灯光。
- 使用的女主身份母版和生成提示词。
- 通过的 QA 项目与验收日期。
- 推荐使用场景和已知限制。

## 使用规则

- 只有 `approved` 资产可以作为新图片或视频的正式丝袜参考。
- `candidate` 仅供复核，不进入自动选择流程。
- `deprecated` 保留历史，但不得继续用于生成。
- 多格总览只供人浏览，不应整张提交给生成模型；实际生成应选择一张最匹配材质和一张最匹配角度/姿势的单独参考。
- 顶层选择入口是 `assets/female-lead/hosiery/README.md`，具体制作项目不得绕过该入口随意选择未登记图片。
