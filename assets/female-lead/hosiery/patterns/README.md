# 丝袜资产｜花纹

本目录保存丝袜花纹母版。当前不预设必须制作的花纹；每一种新花纹经确认后再登记和生成。

## 花纹登记内容

- 中文名称与唯一英文短名。
- 图案单元形状、尺寸和重复间距。
- 图案颜色及其与丝袜底色的关系。
- 允许的厚度、材质和使用场景。
- 正面、侧面、脚背与弯曲区域的变形方式。
- 是否允许图案延伸到脚趾和脚底。

## 共同约束

- 花纹附着于同一片连续袜面，必须随腿部、脚背和脚趾曲率自然拉伸。
- 图案不能像贴纸、纹身、皮肤彩绘或悬浮图层。
- 脚趾前方仍然没有缝合线、加深横线或连接边界。
- 条纹、网格和高对比图案不得制造五指袜式分趾错觉。
- 蹲下时花纹随纤维张力变形，但不应断裂、错位或改变重复规律。
- 花纹下方仍需满足完整包脚、袜面张力曲面、柔化趾甲和暗红甲油规则。

文件名中的无花纹值统一为 `plain`；新增花纹应使用简短、稳定的英文短名，例如经批准后可使用 `polka-dot`，不得用 `pattern1` 等含义不清的名称。
