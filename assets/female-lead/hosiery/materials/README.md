# 丝袜资产｜厚度、颜色与材质

本目录保存丝袜外观变量的标准参考。所有材质图应使用相同脚型、相同高位三分之四机位、自然站姿、中性背景、标准曝光和柔和侧光，以便可靠比较。

## 厚度档位

| 厚度 | 目标表现 |
| --- | --- |
| 10D | 极薄高透；仍必须从脚踝到趾尖看见连续微织纹和柔化证据 |
| 15D | 轻薄透肤；比 10D 稍稳定的色调与光泽连续性 |
| 30D | 日常半透；当前居家造型的主基准厚度 |
| 50D | 中等厚度；轮廓柔化和颜色覆盖明显增强 |
| 80D | 秋冬厚款；接近不透明但仍保留织物层次与合理拉伸 |
| 100D | 高覆盖厚款；强调纤维、保暖感和弯曲处的体积变化 |

## 颜色

- 白色 `white`
- 肉色 `nude`
- 灰色 `gray`
- 黑色 `black`

同一颜色在不同厚度下必须保持色相家族一致，通过透肤度和纤维密度变化体现厚度，不得随意漂移成其他颜色。

## 材质

### 天鹅绒哑光 `velvet-matte`

宽而克制的哑光反射，细腻均匀，适合作为所有厚度的基础材质系列。

### 珠光 `pearl`

柔和、细密、随曲面渐变的珍珠光泽；不得出现散落亮粉、金属片或塑料闪片。

### 缎光 `satin`

方向性更清楚的宽带柔光，随腿部与脚部曲率连续移动；不得变成硬质缎布、乳胶或金属表面。

### 油亮 `oil-gloss`

较强但连续的湿润式光泽，仍需保留纺织微纹和弹性织物属性；不得变成液体油膜、PVC、乳胶或裸肤涂油。

### 羊毛 `wool`

细密保暖纤维、低至中等光泽和更明显的体积感。优先用于 50D、80D 和 100D；10D、15D 等与羊毛物理表现冲突的组合不应为了凑齐矩阵而强行制作。

## 有效组合原则

- 六档厚度、四种颜色和五类材质均属于资产库支持范围，但不默认要求 6 × 4 × 5 的全部组合都成为正式资产。
- 每个进入剧情制作的实际组合，至少补充一张标准高位三分之四材质图。
- 组合必须保持物理可信。例如极薄羊毛、完全不透光的 10D、没有织纹的油亮塑料面均不得登记。
- 材质变化不能破坏 `construction/` 中的完整包脚结构。

## 材质验收

- 脚踝、脚背、趾尖和脚底保持同一色相、密度和表面语言。
- 厚度变化通过透肤度、纤维密度、轮廓柔化和弯曲堆叠体现。
- 光泽必须服从三维曲面和光源方向，不能随机贴在脚趾或腿部。
- 红色甲油的清晰度随厚度增加而下降；任何厚度都不能出现裸露甲面高光。
