# 女主角丝袜专项

本目录只管理女主完整包脚连裤丝袜的结构、材质、鞋履适配和验收规则，不替代女主核心身份，也不保存具体视频的服装或剧情图片。

## 当前状态

当前已有 23 张通过确认或 QA 的视觉模板。目录保持精简，规则由四个入口文件管理，正式图片集中放入 `visuals/`：

- `README.md`：本入口、属性体系、参考图使用方法和登记规则。
- `asset-plan.md`：后续视觉模板与鞋履适配生成清单。
- `closed-foot-pantyhose-toe-lock.md`：脚趾可见时必须逐字加入的英文硬锁。
- `qa.md`：图片、关键帧和视频的验收标准与失败分类。
- `visuals/`：仅保存通过确认、允许作为正向参考的丝袜视觉模板。
- `rejected/`：只保存需要保留供人工识错的失败图；严禁作为正向生成参考。

## 使用顺序

1. 先读本文件，确认目标颜色、厚度、材质、鞋型、视角和姿势。
2. 规划或生成丝袜视觉模板时，再读 `asset-plan.md`。
3. 生成任何含丝袜的画面前读 `qa.md`。
4. 脚趾通过露趾鞋或拖鞋可见时，完整加入 `closed-foot-pantyhose-toe-lock.md`，不得缩写。
5. 正式视觉模板生成后，只有通过 QA 的版本才能作为后续服装图的正向参考。

## 永久结构不变量

- 所有丝袜均为完整包脚连裤丝袜，不是长筒袜、踩脚袜、露趾袜或五指袜。
- 同一片袜面从腿部经脚踝、脚背连续覆盖全部脚趾和足底。
- 袜头前缘无可见缝合线、加深横线、补强带、滚边、绳状凸起或拼接边界。
- 袜面横向跨过相邻脚趾间隙形成柔和浅弧，不得陷入趾缝或逐趾紧贴。
- 脚趾和甲面轮廓必须隔着织物被柔化；暗红甲油只位于脚趾背侧甲板并处于袜面下方，不得呈现裸甲边缘或直接高光，也不得出现在足底、前掌、趾腹或脚趾下侧。
- 褶皱必须服从姿势深度与肉色 30D 的轻薄尺度：中性站立、提踵/踝跖屈和半蹲均保持脚踝、脚背、膝窝、膝前及跟腱—后踝贴体平顺，不出现可辨认的织物褶皱组；全蹲时只允许脚踝前侧出现 2–3 条极细、极浅、低对比压缩纹，膝窝至多一条柔和浅线，褶皱量不得超过旧半蹲模板。任何姿势均禁止厚重横纹、堆叠褶、阴影沟槽、袋状松弛、袜面离体或近似 150D 厚袜的体积感。
- 鞋履、姿势、花纹、厚度和光泽变化不得破坏上述结构。

## 受控属性

- 厚度：`10d`、`15d`、`30d`、`50d`、`80d`、`100d`。
- 颜色：`white`、`nude`、`gray`、`black`。
- 材质：`velvet-matte`、`pearl`、`satin`、`oil-gloss`、`wool`。
- 花纹：默认 `plain`；新花纹必须先在 `asset-plan.md` 登记。
- 标准视角：`front`、`top-three-quarter`、`medial-side`、`lateral-side`、`sole`。
- 标准姿势：`standing-neutral`、`half-squat`、`deep-squat`、`heel-lift`、`leg-cross-bend`。

不要求机械生成全部属性组合。先完成当前需要的有效组合，并拒绝物理冲突，例如极薄羊毛、完全不透光的 10D 或失去纺织纹理的油亮表面。

## 当前基准与兼容边界

当前居家基准是肉色约 30D、微透肉、天鹅绒哑光、无花纹完整包脚连裤袜。

居家拖鞋范围固定为现有两种：S01 浅粉色单条宽面薄底零跟拖鞋、S02 浅象牙粉单条窄面薄底零跟拖鞋。后续不再扩展双带或其他居家拖鞋鞋型；只有这两种现有鞋型的缺失视角或必要受力姿势可以继续补充。

现有英文硬锁包含 `nude-beige` 和 `velvet-matte`，因此在硬锁正式改为材质中性版本前：

- 它只作为肉色天鹅绒哑光系列的正式生成硬锁。
- 白、灰、黑以及珠光、缎光、油亮、羊毛视觉模板先保留在计划中，不直接进入生成。
- 80D、100D 和厚黑丝袜原则上搭配闭趾鞋；不与“每枚暗红甲油必须清楚可辨”的露趾要求强行组合。
- 夹趾鞋与连续袜面存在结构冲突，保持暂停。

## 后续视觉模板的最小参考组合

生成露趾丝袜服装定妆照时，通常只提交：

1. 女主核心身份图。
2. 一张最匹配的全腿丝袜材质图。
3. 一张已经通过 QA 的相同或近似鞋型＋袜头结构图。

不要同时上传整个资产库、多格总览、裸脚解剖图或互相冲突的不同材质参考。裸脚资料即使以后保存，也只能供人检查，不能作为正向生成输入。

## 提示词结构

推荐顺序：

1. 输出类型、构图、视角和姿势。
2. 女主身份与自然身体比例。
3. 目标厚度、颜色、材质、花纹和鞋履。
4. 腿部—脚踝—脚背—脚趾的连续正向织物描述。
5. 姿势中的拉伸、压缩和褶皱。
6. 完整英文硬锁。
7. 简短负面约束、画质和背景要求。

每张参考图必须在提示词中声明唯一职责，避免材质图改变人物身份，或姿势图覆盖目标丝袜规格。

## 文件与登记策略

视觉模板统一放入 `visuals/`，不再为身份、结构、材质、鞋履和姿势建立多层 README。

文件名：

```text
hosiery-{color}-{denier}d-{material}-{pattern}-{shoe-or-none}-{view}-{pose}-vNN.png
```

通过 QA 后在本 README 的“正式资产索引”中集中登记；模板数量明显增加时再拆出一个机器可读的 `catalog.csv`。不为每张图片默认创建同名说明文件，生成提示词和元数据集中记录，避免文件数量再次膨胀。
