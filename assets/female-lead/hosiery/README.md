# 女主角丝袜资产库

本目录规划女主角所有可复用的完整包脚连裤丝袜参考资产。当前先建立目录、命名、组合与验收规范；具体图片将在后续逐批生成、验收并登记。

本资产库只补充丝袜、脚部、鞋履接触和弯曲状态，不替代女主核心身份、身体比例或具体制作项目的服装连续性。当前居家造型仍以肉色约 30D、天鹅绒哑光完整包脚连裤袜为准。

## 生成前必读

生成或修改本目录任何资产前，必须同时读取：

- `AGENTS.md`
- `assets/female-lead/hosiery/media-generation-guardrails.md`
- `assets/female-lead/hosiery/closed-foot-pantyhose-toe-lock.md`
- `assets/female-lead/hosiery/prompt-guide.md`

脚趾入镜时必须完整加入袜头英文硬锁。没有通过 `qa/README.md` 验收的图片不得登记为正式参考。

## 永久结构不变量

以下要求不因厚度、颜色、材质、花纹、视角、鞋履或姿势改变：

1. 所有丝袜均为完整包脚连裤袜，不是长筒袜、踩脚袜、露趾袜或五指袜。
2. 同一片连续袜面从腿部经过脚踝、脚背覆盖至全部脚趾前端。
3. 袜头前缘无可见缝合线、加深横线、补强带、滚边、绳状凸起或拼接边界。
4. 袜面以一整片受横向张力的弹性曲面跨过相邻脚趾间隙，形成柔和浅弧；不得陷入趾缝或逐趾紧贴。
5. 脚趾与甲面轮廓隔着袜面被柔化；暗红色甲油只能作为袜面下的朦胧酒红色块，不得呈现裸露甲面的锐利边缘和直接高光。
6. 花纹只能印织在连续袜面上，不得把花纹边缘误读为袜头连接线、裸露开口或分趾结构。
7. 蹲下或屈腿时，脚踝、脚背、膝前和膝窝的张力、密度变化与褶皱必须符合厚度和材质，袜面不得断裂、消失或变成裸肤。

## 受控属性

### 厚度

`10d`、`15d`、`30d`、`50d`、`80d`、`100d`

### 颜色

| 中文 | 文件名值 |
| --- | --- |
| 白色 | `white` |
| 肉色 | `nude` |
| 灰色 | `gray` |
| 黑色 | `black` |

### 材质

| 中文 | 文件名值 |
| --- | --- |
| 天鹅绒哑光 | `velvet-matte` |
| 珠光 | `pearl` |
| 缎光 | `satin` |
| 油亮 | `oil-gloss` |
| 羊毛 | `wool` |

### 花纹

- 无花纹使用 `plain`。
- 新花纹必须先在 `patterns/README.md` 登记英文短名、尺度、重复方式和允许的厚度范围。
- 不自动假设所有花纹适用于所有厚度、颜色与材质。

### 视角

- 必需：`front` 正面、`medial-side` 内侧、`lateral-side` 外侧、`sole` 脚底。
- 建议：`top-three-quarter` 高位三分之四，用于观察脚踝—脚背—脚趾连续性。

### 姿势

- 基础：`standing-neutral` 自然站立。
- 弯曲：`half-squat` 半蹲、`deep-squat` 深蹲、`heel-lift` 提踵、`leg-cross-bend` 交叠屈腿。

## 组合策略

本库采用模块化参考，不为每一种属性机械生成完整笛卡尔积：

1. `identity/` 锁定女主脚型、脚趾比例、脚踝与暗红甲油。
2. `construction/` 用肉色 30D 天鹅绒哑光无花纹基准，锁定袜头结构和标准视角。
3. `materials/` 在统一视角、姿势与灯光下表现厚度、颜色和材质差异；每个实际需要的有效组合至少一张标准材质图。
4. `patterns/` 只表现花纹设计及其在连续曲面上的变形。
5. `footwear/` 锁定不同鞋口遮挡、接触阴影和袜面可见证据。
6. `poses/` 锁定屈腿、蹲姿和动作中的张力与褶皱物理。

生成剧情图时通常只选三类参考：女主身份母版、最接近的丝袜材质图、最接近镜头角度或姿势的结构图。不要把整个目录或多格总览一次性提交给模型。

## 首批待补资产

### P0｜结构和身份

- 1 组女主脚部身份母版。
- 正面、内侧、外侧、脚底、高位三分之四共 5 张结构母版。
- 全部使用肉色 30D 天鹅绒哑光无花纹丝袜与中性标准光线。

### P1｜标准材质系列

- 六档厚度：10D、15D、30D、50D、80D、100D。
- 四种颜色：白、肉、灰、黑。
- 五种材质：天鹅绒哑光、珠光、缎光、油亮、羊毛。
- 每个进入实际制作的有效组合先生成一张统一的高位三分之四标准图；物理上不合理的组合不得仅为凑齐数量而登记。

### P2｜姿势和鞋履

- 半蹲与深蹲侧面参考，清楚显示脚踝、脚背、膝前和膝窝。
- 薄款、中等厚度、厚款/羊毛各至少一组弯曲参考。
- 常用露趾居家拖鞋、露趾凉鞋和闭趾鞋的适配参考。

### P3｜花纹和视频连续性

- 经确认的花纹母版。
- 提踵、迈步、蹲起和遮挡后重新出现的连续关键帧。

## 文件命名

```text
hosiery-{color}-{denier}d-{material}-{pattern}-{view}-{pose}-vNN.png
```

示例：

```text
hosiery-nude-30d-velvet-matte-plain-front-standing-neutral-v01.png
hosiery-black-80d-wool-plain-lateral-side-deep-squat-v01.png
hosiery-white-15d-pearl-polka-dot-sole-standing-neutral-v01.png
```

版本号递增表示同一规格的新候选。只有通过验收的版本才能写入 `catalog/` 的正式索引；失败结果进入 `qa/` 的失败案例记录，不得冒充正式参考。

## 子目录

- `identity/`：女主脚部身份与解剖比例。
- `construction/`：完整包脚、无连接线和袜面张力曲面的标准结构。
- `materials/`：厚度、颜色、材质与透肤度。
- `patterns/`：花纹定义和曲面连续性。
- `footwear/`：丝袜与不同鞋履开口的接触关系。
- `poses/`：站立、蹲下、屈腿及运动状态。
- `catalog/`：正式资产索引和供人查看的总览。
- `qa/`：验收规范及失败案例分类。

露趾鞋适配资产的逐项生成清单：`footwear/asset-plan.md`。

鞋履适配图使用扩展命名：

```text
hosiery-{color}-{denier}d-{material}-{pattern}-{shoe}-{view}-{pose}-vNN.png
```
