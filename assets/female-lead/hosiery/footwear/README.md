# 丝袜资产｜鞋履适配

本目录保存丝袜与鞋履开口、鞋面、鞋底和脚部接触关系的参考。鞋履资产不得改变丝袜的完整包脚结构。

逐项生成顺序、文件名、优先级和完成状态见：`asset-plan.md`。

## 首批待补类型

- 浅粉色宽面露趾薄底零跟居家拖鞋。
- 较窄鞋面的露趾拖鞋。
- 露趾凉鞋。
- 露脚背闭趾中跟鞋。
- 完全闭趾鞋或短靴。

## 适配要求

- 鞋面遮挡后重新出现的袜面必须与脚踝和脚趾保持同一材质。
- 鞋口阴影不能让脚趾被误读为裸脚。
- 鞋底、鞋面边缘或装饰条不能被误画成袜头连接线。
- 露趾鞋中脚部必须处于正确穿着位置，无空鞋、多余鞋、脚穿出鞋底或鞋履与身体断开。
- 闭趾鞋参考主要用于脚踝连续性，不应声称证明不可见的袜头已经通过验收。
- 每种鞋型至少保留正面和侧面参考；露趾鞋建议增加高位三分之四参考。

## 命名补充

鞋履适配图在丝袜基础文件名中加入唯一鞋型短名：

```text
hosiery-{color}-{denier}d-{material}-{pattern}-{shoe}-{view}-{pose}-vNN.png
```

无脚鞋型母版使用：

```text
shoe-{shoe}-multiview-vNN.png
```
