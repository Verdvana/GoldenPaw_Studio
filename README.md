# GoldenPaw Studio

“赛博金渐层”IP 的可复用角色资产库与系列化视频工程仓库。

## 系列定位

- 女主角与赛博金渐层是固定双主角；后续可以增加固定角色，但不得替换或弱化双主角的核心关系。
- 画面采用真人写实风格，以电影化构图、灯光和镜头运动建立统一的视觉语言。
- 喜剧表达以角色对话、情节反转、反应镜头和表演节奏为主要手段，不依赖一次性视觉噱头。
- 工程面向可持续制作的多集内容：每集可以更换服装和具体场景，但同一人物跨集必须保持长相、年龄感和身体比例。
- 同一场戏内必须保持服装结构、配饰、道具状态、角色站位和场景空间连续。
- AI 生成应优先稳定人物身份、脸部、身材比例、服装结构、鞋袜关系、场景空间及跨镜头连续性；镜头表现力不得以破坏这些稳定项为代价。

## 一级目录

项目内容只沿两条主线组织：

- `assets/`：跨视频复用的角色资产。二级目录是角色，三级目录是该角色的素材类型。
- `products/`：系列中的独立视频工程。二级目录是一集或一条视频工程，工程内只保存该视频专属的策划、分镜、关键帧、提示词、输出与验收记录。

根目录只保留仓库入口文件，例如本 README、`AGENTS.md`、许可证和版本控制配置，不承载媒体素材。

## 开始工作

- 创建或维护通用角色素材：先读 `assets/README.md`，再读对应角色及素材类型的 README。
- 生成或维护某条视频：先读 `products/<视频工程>/README.md`。该文件是视频生成类 AI 的工程入口与执行清单。
- 任何媒体生成或修改：同时遵守 `AGENTS.md`。

## 归档边界

- 能被多个视频复用、用于锁定角色身份或长期视觉设定的内容，归入 `assets/`。
- 只服务于一个视频的剧本、镜头、场景图、关键帧、生成提示词、成片和 QA 记录，归入该 `products/<视频工程>/`。
- 产品可以引用全局资产，但不得把通用母版复制进产品目录。
- 资产目录不得收纳某条视频的剧情镜头或成片。
