# GoldenPaw Studio

当代上海背景的治愈系都市情感 AI 短剧项目。

## 当前规格

- 时代与世界：当代现实世界
- 城市：上海
- 类型：治愈系、都市情感
- 核心关系：女主是猫咪的主人
- 单集时长：3–5 分钟
- 画幅：横屏 16:9
- 影像方向：真人写实感、电影化构图、灯光与镜头运动
- 季节：按单集设定；单集内部须遵循时间和天气连续性

## 核心资产

- `CHR_WOMAN_001`：26 岁中国女性主角
- `CHR_CAT_001`：金渐层猫咪主角
- `EQP_APPLEWATCH_001`：高频设备资产
- `EQP_MACBOOKPRO_001`：高频设备资产
- `EQP_VISIONPRO_001`：高频设备资产

## 工作原则

1. `docs/` 保存规则和设定。
2. `library/` 保存跨集复用并经过审核的资产。
3. `episodes/` 保存每一集实际使用的素材和制作记录。
4. `workspace/` 只用于导入、实验、缓存与临时文件，不能作为正式镜头的长期素材来源。
5. 角色本体、服装、设备和场景分别管理，通过稳定 ID 组合。
6. 原始参考资料与 AI 生成结果严格分开。

## 当前阶段

项目处于前期资产建立阶段。剧情结构、服装系统、场景系统、连续性流程、提示词系统和技术测试将在后续逐步补充。
