5. 失态后舔爪掩饰

## 4. 五秒动作测试包

关键帧：`assets/cyber-golden-shaded/motion-tests/typing-lick-paw-keyframes-v1.png`

视频提示词与逐秒节奏：`assets/cyber-golden-shaded/motion-tests/typing-lick-paw-motion-test-v1.md`

当前环境没有可直接输出连续视频的生成工具，因此本项交付为六关键帧和完整视频生成规范。接入视频模型后应以身份母版作为角色参考，以关键帧作为动作和连续性参考。

## 一致性优先级

1. 身份母版：脸、眼睛、鼻子、毛色和整体气质
2. 标准多视角：身体结构和尾巴
3. 表情动作图：表演幅度
4. 设备交互图：猫与设备的尺度和接触方式
5. 动作关键帧：镜头连续性和时间节奏
