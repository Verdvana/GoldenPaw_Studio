# CHR_CAT_001

金渐层猫咪主角，`CHR_WOMAN_001` 的宠物和陪伴者。

## 已有资产包投放位置

请将现有猫咪 ID 资产包完整放入：

```text
library/characters/CHR_CAT_001/source_assets/
```

如果资产包自身已有目录结构，请原样保留，不要先拆散。导入后再检查内容、版本、命名和重复文件，并从中建立正式参考板。

## 目录说明

- `source_assets/`：已有原始资产包和来源文件
- `face/`：脸型、耳朵、眼睛、鼻头参考
- `coat_markings/`：额头、眼周、背部、胸口和尾巴毛色分区
- `body/`：体型、身长和腿长比例
- `paws_and_tail/`：爪部和尾巴专项参考
- `expressions/`：表情和情绪状态
- `poses/`：坐、卧、站、走、跑、跳等姿态
- `reference_sheets/`：统一角色参考板
- `model_assets/`：未来的角色模型和生成配置
- `tests/`：身份与结构稳定性测试
- `approved/`：批准用于正式生产的猫咪资产
