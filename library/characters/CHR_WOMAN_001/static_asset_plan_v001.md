# 女主独立静态资产正式计划 v001

状态：`IN_PRODUCTION`。ID01 v004 与 ID02 v003 为正式资产；ID02 后续候选不替换当前正式选择。

计划包含 **47 个编号任务**，允许复用，因此实际新图片可以少于 47 张；另有 **1 个条件任务 FT01**，只在现有全身图无法检查包趾结构时生成。重试版本不增加任务编号。

## 1. 角色设定与范围

- 角色：`CHR_WOMAN_001`，26 岁中国女性，现居上海，猫咪主人；身高 168cm 为用户给定设定，不是照片测量结果。
- 真人照片已入库，用户已说明取得本人授权。原文件仅作来源，保留不覆盖。
- 发型 A 来源：`source_photos/DSC01015.JPG`，可见披散长发；发色受户外光影响，不据此直接锁定染发色号。
- 发型 B 来源：`source_photos/DSC01276.JPG`，可见头发向上／后收起、脸侧留碎发；后脑固定采用用户确认的“盘发＋鲨鱼夹”结构。鲨鱼夹的颜色、材质、尺寸和齿形在 HB03 中形成正式影视补全设计并提交确认。
- 两套发型属于同一人，可随集切换；同场连续镜头保持发型 ID 一致，除非剧情明确换发型。
- 除下列用户指定的影视化身份基线外，不再自动美颜、瘦脸、放大眼睛、增高、拉长腿、缩腰或改变身体体积。角色年龄为 26 岁，不据照片推断本人年龄。
- 用户指定的影视化身份基线属于正式角色设计：双眼视觉尺寸约增加 5%、脸部视觉宽度约收窄 5%、加入自然淡妆；全身腿部视觉占比相对 ID02 v001 约增加 5%。这些变化必须保持克制并在后续资产中稳定，不得逐代累积。
- ID02 v002 的腿长比例和大腿至足部丝袜质感已由用户确认，作为固定视觉目标；后续从原照重新生成时用文字规格重建，不以旧生成图作为底图。
- ID02 v003 的脸部身份与身材比例由用户确认为当前目标；ID01 必须与该脸部身份一致。ID02 的趾根以下不得出现变浅或材质分界。
- 基准资产采用克制的自然日常妆感，不主动添加耳饰、项链、手表或其它配饰；手指甲保持自然状态，双脚红色指甲油按鞋袜规则执行。
- 生成角度只能作为基于参考的设计候选，不能当作照片未展示结构的客观还原证据。
- 本计划不生成猫咪同框、人猫比例、剧情日常裙装 LOOK、设备交互、正式场景或视频。

## 2. 身体测试造型与鞋袜规则

- 身体可见的身份母版、身体转面、自然姿态和鞋袜验证统一使用：粉色高叉一件式泳衣、肉色轻哑光天鹅绒观感包脚连裤袜。
- 连裤袜隐约透出肤色和红色脚趾甲；袜子穿在泳衣内，袜腰与缝线本体不直接露出，泳衣表面可以呈现符合面料厚度的轻微内层轮廓。
- 基准状态不穿鞋，但仍穿完整包脚连裤袜，禁止描述或生成为赤脚。
- 泳衣和鞋类按文字设计。泳衣不得用厚胸垫、塑形收腰或其它结构改变身体视觉体积。首张测试造型获批后，同批固定剪裁、颜色、面料、袜色、透度和层级。
- 女主只有三类鞋状态：不穿鞋、平底鞋、5cm 高跟鞋；不生成其它跟高。露趾鞋仍保持包趾袜，不能变成裸趾。
- 双脚脚趾甲固定为稍深的红色，以克制的深红／酒红视觉范围为准；手指甲颜色未指定，不自动涂红。红甲必须受袜层的颜色、透度和纹理影响。
- 趾间袜面形成连续、柔和的物理张力曲线，不能做成五趾袜或裸趾染色。全蹲等强弯曲姿态允许踝前、腿弯出现随材质变化的轻微褶皱，不生成松垮堆袜。
- 后续剧情造型以裙装为主，并且必须搭配连裤袜；具体颜色、材质、厚度与鞋款按每套 LOOK 单独登记。
- 完整硬性规则见 [女主造型强制约束](../../wardrobe/CHR_WOMAN_001/mandatory_constraints.md)。

- 实际袜色由目录语义、文字规则及中性电影柔光下获批的测试造型母版确定，不从商品图像素取色。每个任务最多选择同类 1–3 张并逐图注明职责。

## 4. 灯光、色彩与迭代规则

- 使用大面积漫射主光、适度柔和补光和稳定中性白平衡，形成电影摄影式柔光，同时保留真实身体体积。
- 母版不添加彩色边光、重 LUT、强暗角、过度锐化、磨皮或模拟颗粒。
- 大腿、小腿、膝部、脚背、脚趾、泳衣及背景纯色区必须保持连续明暗过渡，不得出现随机色块、局部染色或商品图滤镜色偏。
- 新角度从干净真人参考与已批准母版独立派生，不把连续多次修改后的图片作为唯一参考。每次只修一个问题；色块或色偏加重即停止该分支，从干净输入重开。最多连续编辑两次。
- 袜面张力、轻微褶皱和身体阴影不能被当作色块全部磨平，也不能用“物理褶皱”解释随机斑驳。
- 完整规则见 [色彩与袜面质量控制](../../../docs/production_rules/color_and_fabric_quality.md)。

## 5. 生成顺序与关卡

1. 建立授权原照清单，标注每张照片的身份、身体、发型、表情用途及透视／光线局限。
2. 生成 ID01；用户确认脸部身份后再生成 ID02。
3. 用户确认 ID02 的身体比例、测试造型、袜色和材质后，制作脸部角度、身体转面与发型结构。
4. 两套发型结构确认后，制作表情；不为发型 B 机械复制所有表情。
5. 制作自然姿态、手部和鞋袜验证。PS06 与 TX01、ID02 与 FT01 可在满足分辨率时复用。
6. 每一小批审核后再进入下一批，不一次生成全部任务。静态完成后另行规划剧情 LOOK、人猫互动、设备和动态测试。
