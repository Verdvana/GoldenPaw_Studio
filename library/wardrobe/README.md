# 服装资产库

女主已生效规则见 [强制约束](CHR_WOMAN_001/mandatory_constraints.md)：日常以裙装为主、必搭连裤袜、红色脚趾甲及包趾连续性。下方“不预设具体造型”不覆盖这些已确认规则；粉色泳衣测试造型仍待参数确认。

服装是本项目的重点系统，当前只建立入口，不预设具体造型。

- `CHR_WOMAN_001/`：女主服装、鞋袜、饰品与整体造型
- `CHR_CAT_001/`：猫咪项圈、吊牌、领巾、胸背和服装

角色身体身份与服装资产必须分开。经典造型放入 `signature_looks/`，随季节或剧情变化的造型放入 `seasonal_looks/`。每套造型后续使用唯一 `LOOK_*` ID，并拆分记录单件、穿着层级及鞋袜关系。
