# Outfit Package Placeholder

Replace `_example` with a stable outfit ID and copy `templates/outfit/OUTFIT.md`. Outfits are L2 design assets and cannot redefine Character Canon.

Use the package contract in the template for all outfit folders. Put supplied
clothing references in `reference_inputs/garment_references/`, with one provenance
record per image. References containing models are garment-only inputs: the model,
face, body, skin, hair, pose, lighting, background, and photography style must be
explicitly excluded.

`worn_front`, `worn_3q`, and `worn_back` are fit-validation assets only. They are
not video keyframe references and must follow the source-derived Face method when
the owner's face is visible.
