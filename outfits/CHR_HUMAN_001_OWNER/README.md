# Character Outfit Root

Canonical layout for this character's future outfit packages:

```text
outfits/CHR_HUMAN_001_OWNER/<OUTFIT_ID>/
├── OUTFIT.md
├── reference_inputs/garment_references/
├── approved/
└── candidates/
```

All current Owner outfit packages live under this character root. New outfit
packages must also be created directly here. Do not copy or move approved rasters
solely to create a second physical file.
