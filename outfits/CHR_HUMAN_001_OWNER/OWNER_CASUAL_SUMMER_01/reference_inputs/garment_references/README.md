# 夏季休闲穿搭：照片参考

请把服装、鞋子、包、配饰及需要说明的材质照片放入此目录：

`outfits/CHR_HUMAN_001_OWNER/OWNER_CASUAL_SUMMER_01/reference_inputs/garment_references/`

建议文件名：

- `clothes_front.jpg`：正面整体服装
- `clothes_back.jpg`：背面结构（如需要）
- `clothes_detail_01.jpg`：面料、纹理或工艺细节
- `shoes.jpg`：鞋子
- `accessories_01.jpg`：包或配饰

可以直接使用你自己的文件名；放入后把文件名补到上一级
`OUTFIT.md` 的 `garment_reference_files`。照片中的人物仅作为服装展示，
不得作为人物身份、脸、身体、皮肤或头发参考。
