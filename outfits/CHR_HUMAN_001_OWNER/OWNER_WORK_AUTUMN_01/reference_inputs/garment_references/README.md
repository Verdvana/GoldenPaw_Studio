# Garment References

Place the upcoming autumn-officewear reference images in this directory. Keep
one immutable source file per reference and add a matching
`REF_<NNN>_PROVENANCE.md` record before it is used.

Each reference may define only declared garment responsibilities, such as
silhouette, layering, palette, fabric finish, construction, footwear, or
accessories. It must not define the owner's model identity, face, body, skin,
hair, pose, lighting, background, or photographic style.

This directory currently contains no approved or generation-ready references.
